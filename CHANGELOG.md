# Changelog

All notable changes to FixtureGuard are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-02

### Added

- High-confidence detection for user-home, temporary, runtime-user, and
  process-specific paths across Windows, Linux, and macOS fixtures.
- Private and link-local IPv4 detection for topology-dependent snapshots.
- Value-free text, JSON, and SARIF diagnostics with exact source coordinates.
- Path-scoped SHA-256 baselines that never store matched fixture content.
- Symlink, binary, size, include, exclude, and rule-disable boundaries.
